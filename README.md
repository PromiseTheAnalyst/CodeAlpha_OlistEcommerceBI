# Executive Summary

Business Intelligence is more than creating dashboards it's about transforming raw data into meaningful insights that support strategic decision-making.

This project explores the **Olist Brazilian E-commerce Dataset**, applying an end-to-end Business Intelligence workflow to uncover trends in sales performance, customer behavior, product performance, delivery efficiency, and business growth.

Using SQL for analytical querying, Excel for data preparation, and Power BI for interactive reporting, the goal is to convert transactional data into insights that decision-makers can understand and act upon.

---

# Business Challenge

Modern e-commerce companies generate massive volumes of transactional data every day.

Without proper analysis, it becomes difficult to answer questions such as:

- Where is revenue coming from?
- Which products drive business growth?
- Are customers receiving orders on time?
- Which regions perform best?
- How efficient are delivery operations?
- What trends should management monitor?

This project addresses those questions through Business Intelligence techniques.

# SQL Analysis

SQL is used to translate business questions into measurable insights.

Concepts applied include:

- INNER JOIN
- LEFT JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions
- DATEDIFF()
- Ranking Functions
- Subqueries
